# 🍅 Pomodoro Timer

Odaklan, dinlen, tekrarla.

JavaScript, HTML ve Bootstrap ile yapılmış sade ve işlevsel bir Pomodoro zamanlayıcısı.

---

## Özellikler

* **3 Mod:** Pomodoro, Kısa Mola, Uzun Mola
* **SVG Halka Animasyonu:** Süre azaldıkça çember görsel olarak daralır
* **Başlat / Durdur / Sıfırla:** Tam zamanlayıcı kontrolü
* **Özelleştirilebilir Süreler:** Her mod için dakika ayarlanabilir
* **Tamamlanan Pomodoro Sayacı:** 🍅 emojileriyle görsel takip
* **Otomatik Mod Geçişi:** Pomodoro bitince kısa molaya, mola bitince pomodoroya geçer

---

## Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

---

## Dosya Yapısı

```
pomodoro/
├── index.html
├── style.css
└── script.js
```

---

## Kurulum

1. Repoyu klonla veya dosyaları indir
2. `index.html` dosyasını tarayıcıda aç
3. Kullanmaya başla, kurulum gerekmez

---

## Kullanım

1. Mod seç: 🍅 Pomodoro / ☕ Kısa Mola / 🛋️ Uzun Mola
2. **Başla** butonuna bas
3. Süre bitince otomatik olarak sonraki moda geçer
4. Alt kısımdan süreleri dakika cinsinden özelleştirip  **Kaydet** 'e bas
